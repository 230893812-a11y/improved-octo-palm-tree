# 浪尖儿·坦克大战（快速体验版）

这是根据原 `tank_battle_web.py` 的玩法重构的纯静态 HTML5 Canvas 版本。保留玩家移动、射击、敌人 AI、障碍物、基地、生命值、分数、爆炸效果、音效和手机虚拟按键；不依赖 Python、Pygbag 或 WASM，适合 GitHub Pages。

## 打开

直接双击 `index.html` 即可运行；也可以在此目录启动任意静态服务器。上传 GitHub 时，把本目录内的 4 个文件全部上传，进入仓库 Settings → Pages，选择 `main` 分支和 `/ (root)` 保存。

原 Pygbag 完整版仍保留在“浪尖儿坦克大战-最终提交/网页版/web_build.tar.gz”。
